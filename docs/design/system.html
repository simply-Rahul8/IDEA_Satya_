Design system · draft v0.1

Calm, warm, exact.

Warm paper neutrals, one plum accent ("Jamun"), editorial serif for display and a legible sans for everything you read twice. Use the toggle top right to see dark. Full rationale in design-system.md.

Colour

Severity colours are reserved for flags and always travel with an icon and a word. The accent is never used for severity.

Type

Display: Fraunces (fallback Newsreader, Georgia). Body: Inter (fallback Noto Sans, system). Hindi: Noto Sans Devanagari at 1.75 line-height. Fluid sizes from 360px up. Specimen below uses the fallback stack because fonts are not bundled in this draft.
